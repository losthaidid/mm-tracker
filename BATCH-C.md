## Ticket matching

Matching uses deterministic text rules on the signed-in account's current tickets, without AI, network requests or record changes. Searches are briefly debounced and the bounded index is rebuilt after records change. Exact descriptions and ticket identifiers rank highly; shared meaningful words/codes also match. Results explain the shared terms, rather than presenting a confidence percentage. They are suggestions for the user to assess, not proof of duplicate issues. Editing excludes the current ticket. History and user text stay escaped; the existing ticket save, status, milestone and history flows remain in charge.

## Screenshot workflow

The guide builder includes the ten requested document enhancements:

| No. | Feature | Controls and behaviour |

All document settings, structured text and comparison images are retained in editable guides. Brand templates and recovery copies use local browser storage; they are not uploaded to Supabase or included in account backups. If browser storage fails, save an editable guide for an external copy. Privacy-editor drafts remain in memory.

The screenshot guide uses three workspaces: **Edit screenshots** puts the numbered step rail beside a larger canvas and instructions/object inspector; **Design & layout** pairs a scrollable settings sidebar with the live document preview; **Preview & export** gives the document its own wider reading space. The compact header shows the maintained guide name, recovery options sit beside the save status, and export controls remain available at the bottom. Select, Move, Numbers, Arrow, Rectangle and Crop stay on the quick toolbar; the remaining tools are grouped in **More tools**. Switching workspaces keeps the same canvas, controls, unfinished text and prepared downloads. Adding a base screenshot returns to Edit. Keyboard navigation between workspace tabs does not move selected annotations. The screenshot privacy editor keeps its existing layout.

Designed exports use a smaller running guide title after the first numbered page. Cover image frames adapt to screenshot proportions. Contents entries include a numbered badge, an edited screenshot thumbnail, the step title, a short instruction excerpt and the guide page number. Thumbnails use the same flattened screenshot as the guide, retaining privacy covers, crops and image layers.

The editor fills the browser window. Choose a tool and drag on the screenshot. **Move** permits scrolling/panning, including touch scrolling on phones. Brush size and colour apply to marks; arrow strokes use a finer width. **Crop** chooses the exported area. **Compare original** is only an editing view: exports always contain the current edits and crop. Solid covers replace pixels in the exported image; blur softens detail. Originals remain available in the draft. **Add edited image to a guide** transfers a flattened image with its title/caption.

**Numbers** adds numbered screenshot markers: click to place 1, 2, 3 and drag before releasing to adjust the placement. Numbering restarts for each screenshot and resumes after the highest saved marker. Use **Colour** and **Marker size** to style new markers. Labels automatically use a readable contrast colour, and bubbles stay within the image edges. **Rectangle outline** lets you drag an unfilled border around any area; **Colour** and **Border thickness** style new outlines. Existing arrows, covers, blur and crop remain available. Both new tools support Undo/Redo, Compare original, Save/Open editable guide, live preview and PDF/JPG/PNG export in all three guide layouts. They also work in Screenshot privacy.

**Select objects** edits existing annotations. Click an object or select it from **Objects & instructions**, drag to move, and drag a corner to resize. Exact Left/Top/Width/Height percentages, colour, size, number, text and opacity can be changed with **Apply object changes**. Resize a text box or reduce its text size if the label does not fit. Arrow keys nudge the selection (Shift for ten pixels); Delete removes an unlocked selection. **Lock object** protects it from selection gestures and editing until explicitly unlocked. The object list can still select locked items. **Duplicate**, **Bring to front** and **Send to back** control individual layers. Edits, movement, deletion, duplication, layer changes and locks support Undo/Redo. Selection outlines and handles appear only in the editor.

**Delete selected object** is also available beside the canvas, with selection and lock guidance below the toolbar. Choose an object on the canvas or in the object list, then delete it; Undo restores it. Deleting an object leaves the base screenshot and other objects intact. Delete/Backspace do not delete objects while typing in text fields.

**Add image layer** places one or more PNG, JPEG or WebP images above the selected screenshot. Each image is an independent object with its own name, position, size, opacity (5–100%), lock and stacking order. Images initially fit within the current crop; drag them with Select objects, resize their box, or maintain exact percentages. Images fit their boxes without stretching and retain transparent backgrounds. Deletion, Undo/Redo, duplication, copy/paste across screenshots and Save/Open editable guide include image layers. Layers appear in the editor, live preview and PDF/JPG/PNG exports; comparison still shows the untouched base screenshot. Annotation styles leave uploaded image colours unchanged.

**Front cover · text, fonts & images** adds an optional A4 opening page before the screenshot steps. Choose **Accent band**, **Editorial** or **Image spotlight** and left or centered text. Title, subtitle and details each have independent Sans serif / Serif / Monospace font and text-size controls. A blank cover title uses the guide title. Add up to three cover images, reorder them to change the leading image, or remove them individually. Images retain their proportions and transparency. The cover uses the guide's export colours and footer; it is unnumbered, and screenshot page/step numbering starts normally after it. Excess text produces a clear fit error instead of clipping; shorten it or reduce its size. **Preview front cover** opens the live preview, where **First guide page** switches to the screenshot content. Save/Open editable guide preserves all cover settings and images. Older files open with the cover disabled.

Additional tools: **Oval outline** draws an unfilled circle/ellipse; **Text label** and **Callout bubble** place maintained text; **Spotlight** dims the area around a selected rectangle with maintained colour/opacity. Enter Label text before using a text tool. **Zoom detail** magnifies a small selected area into a separate box; move or resize that box with Select objects. Its source frame remains anchored to the chosen area. Every cover, brush and blur edit is applied to the zoom source regardless of layer order, so magnification does not recover concealed original pixels. **Compare original** remains a separate editing view.

**Copy selected** or **Copy all** copies annotations locally. Select another screenshot and **Paste objects** to reuse relative positions; pasted items are unlocked and numbered markers receive new numbers. The source screenshot is not copied. Zoom source coordinates apply to the destination screenshot. Copy/paste and edits are validated before replacing the current marks; an oversized or invalid paste leaves them intact. The clipboard is cleared on account changes and page exit.

**Linked instruction** belongs to a number marker. Enable **Include numbered instructions in exports** to add its matching numbered text beneath the screenshot; selecting an instruction in the editor selects its marker. Caption text is retained. **Numbering options** supports a starting number (1–999), restarting per screenshot or continuing across the guide. New markers follow the selected sequence. **Renumber existing markers** explicitly updates the current screenshot or guide; Undo remains available on each affected screenshot.

**Saved annotation styles** stores up to twelve named sets of colour, stroke, marker size, text size and spotlight opacity inside the editable guide. Apply a style to the current tool and selected unlocked object, or delete it from the list. Save/Open editable guide preserves styles, sequencing, linked instructions, locks, layers and every object. Older files receive the original per-screenshot numbering and no linked-instruction/style settings. Per screenshot, caption plus object text is bounded to 12,000 characters; each label is at most 500 and each numbered instruction 300 characters.

**Export layout** offers **Guided walkthrough** (numbered, full-width screenshots with short steps sharing pages), **Split view** (screenshots on the left and instructions on the right), and **Quick reference card** (two-column step cards, with unused page height trimmed). New guides start with Guided walkthrough. Older editable guides keep their original one-step-per-page layout until another layout is chosen. The selected layout is saved in editable guides and used by every PDF/JPG/PNG guide export. Quick-reference PDFs use the same compact page proportions as their exported images; the other layouts use A4.

**Refreshed guide pages** use a branded colour band, larger guide title, numbered step cards, framed screenshots, clear **What to do** sections and separate numbered-instruction rows. Page footers and uploaded transparent branding remain maintained separately. Guided walkthrough can gently reduce two short screenshots together (at most 20%) when that keeps both complete steps on one page. A complete step moves to the next page if it fits there; oversized instructions still continue without losing text. Portrait, square and wide screenshots retain their aspect ratio and are centered within their frames. Quick reference trims unused page height; Split view retains A4 with side-by-side content. All three designs adjust text contrast for custom light, dark and middle-tone paper. The **Original layout (minimal)** option retains the legacy one-step-per-page appearance for older guide files; choose one of the three maintained layouts for the refreshed style.

Changing the layout opens **Live export preview**, selects **Full page** and updates automatically. The full-page and footer views support both A4 and compact page dimensions. Colours, footer transparency, logo size/position, crops and annotations carry across layouts. Long instructions continue without losing text, and footer space remains reserved on every page.

**Export heading** controls the small banner at the top of every guide page, separately from the guide title. Replace `WORKHUB / SCREENSHOT GUIDE` with your organisation or guide label (up to 180 characters), or leave it blank to hide the banner. Long headings wrap above the title and are repeated on continuation pages. Editing it clears an already-prepared download; prepare the guide again to include the change.

**Live preview, export colours, footer logo & watermark** opens the guide branding controls. Choose Green, Blue, Purple or Charcoal, or maintain custom **Accent colour** and **Page background** values. These apply to PDF/JPG/PNG guide pages, independently of the website theme. Text adjusts for readability against custom backgrounds; screenshots and uploaded logos retain their colours.

Add a transparent PNG/WebP logo (up to 2 MB), optional footer text (120 characters), Left/Center/Right alignment and Small/Medium/Large logo size. **Footer opacity** (5-100%) fades the logo and footer text for a watermark effect. The editor shows transparency on a checkerboard; the exported footer has no background box. Existing opaque image backgrounds are preserved. JPG cannot carry alpha transparency, so a transparent logo is composited directly against the selected page colour.

Fine logo controls add **Logo width**, **Horizontal position** and **Vertical position** sliders. Wide footer images can fill the page content width; aspect ratio is preserved within the footer area. The printed A4 dimensions are shown beside the controls. Alignment and size presets remain available; **Reset logo placement** restores the original centered medium placement. Exact adjustments are retained in editable guides, and older guides retain their original placement.

**Live export preview** updates automatically while the branding panel is open. Browse every exported page with thumbnails, Previous/Next or the page selector; use zoom, Fit preview and Footer close-up to inspect the selected page. The preview shares the export renderer and includes covers, contents and continued instructions. Rendering is debounced and limited to one document job at a time. Only thumbnails and the selected full-size page are retained. Closing the panel/editor or switching accounts cancels pending work and releases preview images.

Branding repeats on every guide page, including caption continuations. Space is reserved above the unchanged step/page numbering, keeping long captions clear of the footer. Save/Open editable guides retain colours, footer settings and the embedded logo. Older guides default to the original green palette and no footer. Logo imports stay local, preserve alpha and are normalized to a maximum of 1600 × 600 pixels; replacing a logo or changing branding invalidates prepared downloads.

PNG exports contain the edited image. Guide PDF/JPG/PNG pages also contain the maintained heading, step numbers, titles and captions. JPG and PNG page collections download as ZIP files with numbered pages; JPG uses actual JPEG encoding. Long captions continue onto extra numbered pages. PDF text is rasterized for Unicode font compatibility and is not selectable. Prepare the file, then select its explicit download link. PDF ZIP is available for browsers that intercept a direct PDF download.

Images and guide drafts do not sync to Supabase or appear in account backups. Closing the editor keeps the in-memory draft and flushes enabled recovery saving. **Save editable guide** downloads a `.workhub-guide.json` file; **Open editable guide** restores its heading, steps and edits atomically after validation. Older editable files open with the original WorkHub heading; an explicitly blank heading stays blank. Editable files contain original images as well as annotations: use PDF/JPG/PNG exports for sharing. Replacing a local draft never changes cloud records. Account changes and leaving the page clear in-memory images, drafts, previews and ready links; pending UI work is cancelled. Recovery copies remain in account-scoped browser storage until cleared or site data is removed, and are only restored for the same signed-in account.
