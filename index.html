Saving, security, backups, imports, and reports

Sign in with the same tracker login on every device. Changes upload automatically; save status and recovery actions are in Settings. If the connection drops, changes wait in this browser and retry automatically.

Restore and Reload cloud records require the current account email and password. Deleting scheduled or planned activities requires the current password. Credentials are verified by Supabase Auth and are never stored in tracker data.

Tasks can link to projects, tickets, or custom references. Milestones, project activities, work locations, project phases, phase-gate criteria, departments, structure items, master-data items, and visible screens can be maintained from Settings. Weekend project and ticket-linked work is marked TOIL.

Company/process Excel imports are previewed first. Only normalized mapping rows are saved online; the selected workbook itself is not stored. Project items can link to imported companies and include expected and due dates. Phase gates can be accepted or skipped. These records are included in backups and the formatted Excel report.
