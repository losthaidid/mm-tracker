Saving, security, backups, imports, and reports

Sign in with the same tracker login on every device. Changes upload automatically; save status and recovery actions are in Settings. If the connection drops, changes wait in this browser and retry automatically.

Use Forgot password? to receive a secure recovery email without creating another account. Signed-in users can change their password under Settings → Account. Password changes keep the same private cloud records.

Restore and Reload cloud records require the current account email and password. Deleting scheduled or planned activities requires the current password. Credentials are verified by Supabase Auth and are never stored in tracker data.

Tasks can link to projects, tickets, or custom references. Milestones, project activities, work locations, project phases, project item types, phase-gate criteria, Phase Feedback categories, departments, structure items, master-data items, and visible screens can be maintained from Settings. Weekend project and ticket-linked work is marked TOIL.

Companies and individual processes can be added manually, while Excel imports remain available for bulk mapping and are previewed first. Use Companies & processes → Manage SAP MM areas to add, rename, reorder, show or hide areas for a project. Hiding an area preserves its records and reports. Project items support smaller status-tracked sub-items. A project’s saved Go-Live date appears automatically in Overview, Project Timeline, and Schedule without reserving working hours. Phase Gates track acceptance by company with owners, target dates, blockers, readiness, and explicit skip reasons. Phase Feedback links to project items and can create tasks, project items, schedule actions, gates, or decisions. These records are included in backups, traceability, phase packs, and the formatted Excel report.
